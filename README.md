# Git Basics Cheat Sheet

- git init     : Initialize a new repository
- git status   : View file changes and staged files
- git add      : Stage files for commit
- git commit   : Record changes to the repository
- git push     : Upload local commits to remote (GitHub)
- git pull     : Fetch & merge changes from remote (GitHub)
